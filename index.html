여기콕 도움 버튼 팀 시안 · 0.6.4 · 2026-11-12

병원 예약 화면 위에 “지금 이걸 누르세요”를 한 단계씩 알려주는 버튼이에요. 병원이 코드 한 줄을 넣으면 뜨는 것을, 병원이 넣기 전에 우리끼리 미리 써 보는 페이지예요.

이 페이지는 인터넷에 올린 뒤에 쓸 수 있어요. 지금은 내 컴퓨터의 파일로 열려 있어서 병원 사이트가 이 코드를 불러오지 못해요.

컴퓨터에서 써 보기

  1. 아래 노란 버튼을 북마크바로 끌어다 놓으세요. (북마크바가 안 보이면 ⌘⇧B, 윈도우는 Ctrl+Shift+B)
  2. 병원 사이트를 열고, 북마크바의 여기콕 켜기를 누르세요.

?여기콕 켜기

이 버튼을 여기서 누르면 아무 일도 없어요. 북마크바에 옮긴 뒤 병원 사이트에서 눌러야 해요.

휴대폰에서 써 보기

복사했어요

아이폰 (사파리)
  1. 처음 한 번만: 아이폰 설정 → 앱 → Safari → 탭에서 하단을 고르세요. 그래야 사파리 아래에 책 모양(북마크) 버튼이 보여요.
  2. 이 페이지에서 위 ① 켜는 코드 복사를 누르세요.
  3. 아래 공유 버튼(네모에 화살표) → 북마크에 추가 → 오른쪽 위 저장.
  4. 아래 책 모양 → 방금 만든 여기콕 시안을 꾹 누르고 → 편집.
  5. 주소(https://…)를 모두 지우고, 빈 칸을 꾹 눌러 붙여넣기 → 저장.
  6. 병원 사이트를 열고, 책 모양 → 여기콕 시안을 누르세요.

로그인처럼 화면이 통째로 바뀌면 도움 버튼이 사라져요. 그때마다 책 모양 → 여기콕 시안을 한 번 더 누르세요.

갤럭시 (삼성 인터넷)
  1. 위 ① 켜는 코드 복사를 누르세요.
  2. 아래 막대의 메뉴(≡ 또는 ⋮) → 현재 페이지 추가 → 북마크를 누르세요.
  3. ‘북마크 편집’ 화면이 떠요. 이름을 여기콕으로 바꾸세요.
  4. 웹 주소 칸을 눌러 모두 지우고, 꾹 눌러 붙여넣기 → 저장.
  5. 병원 사이트를 열고, 아래 막대의 북마크(☆) → 여기콕을 누르세요.

북마크 목록에서 눌러도 안 켜지면, 주소창에 여기콕이라고 쓰고 아래에 나오는 ☆ 여기콕을 눌러 보세요.

갤럭시·안드로이드 (크롬)
  1. 위 ① 켜는 코드 복사를 누르세요.
  2. 오른쪽 위 ⋮ → ☆ 를 눌러 이 페이지를 북마크하세요.
  3. 다시 ⋮ → 북마크 → 모바일 북마크에서 ‘여기콕 시안’ 옆의 ⋮ → 수정을 누르세요.
  4. 이름을 여기콕으로, URL 칸은 모두 지우고 붙여넣기 → 왼쪽 위 ←를 누르면 저장돼요.
  5. 병원 사이트를 열고, 주소창에 여기콕이라고 쓰면 아래에 ☆ 여기콕이 나와요. 그걸 누르세요.

크롬은 북마크 목록에서 바로 누르면 안 켜져요. 꼭 주소창에 이름을 써서 눌러야 해요.

써 볼 병원

고려대학교 안암병원첫 화면부터 회원가입·로그인·예약 직전까지 모두 안내해요 서울대학교병원첫 화면부터 로그인까지 안내해요

다른 병원 사이트에서도 켤 수 있어요. 그때는 화면에 적힌 말을 읽어서 안내하는 ‘공통 안내’로 움직여요.

써 볼 때 알아둘 것

  1. 화면이 통째로 새로 열리면 한 번 더 눌러야 해요. 시안이라서 그래요. 병원이 코드를 넣으면 모든 화면에서 저절로 떠요.
  2. 증상을 쓰는 창의 ‘예약하기’를 누르면 실제로 예약이 잡혀요. 써 볼 때는 그 창에서 ‘취소’를 누르세요. ‘간편예약 신청’·‘예약신청’도 실제로 접수돼요.
  3. 입력한 이름·번호는 어디로도 보내지 않아요. 화면에 빈칸이 남았는지만 그 자리에서 봐요.
  4. 크롬 확장 프로그램 ‘여기콕’을 깔아 둔 컴퓨터에서는 확장을 잠깐 꺼 주세요. 둘 다 켜면 버튼이 두 개 떠요.

병원이 넣는 코드 한 줄

병원 홈페이지의 공통 틀(모든 화면에 들어가는 부분)에서 </body> 바로 앞에 넣어요.
